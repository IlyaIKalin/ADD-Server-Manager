# ADD Server Manager 0.9.91 — вариант с FPS движка

Вариант для серверов с Expansion Core, с TL_Core или без него. Протокол 2,
настройки подключения и формат heartbeat сохранены. Изменён только подсчёт FPS.
Ограничение каталога предметов до 80 классов каждого раздела сохранено по просьбе пользователя.

## Установка

1. Остановить сервер и распаковать папку `@ADD_Server_Manager_FPS` рядом с модами.
2. Заменить оригинальный ADD_Server_Manager в списке `-mod` этой папкой.
   Если оригинал был подключён через `-serverMod`, заменить его там же.
   Сохранить используемый способ подключения: оригинальный мод содержит клиентский UI.
3. Не подключать оригинальный и этот вариант одновременно: оба содержат
   классы и PBO `ADD_Server_Manager`.
4. Expansion Core должен оставаться подключён. Файлы профиля
   `ADDEV/ADD_Server_Manager/ADD_Server_ManagerSetting.json` менять не требуется.
5. Запустить сервер, проверить script/RPT-логи и дождаться двух heartbeat
   (обычно около минуты). Сравнивать FPS с консолью на одинаковом интервале.

Папка содержит два PBO: мод с заменённым `ADD_Ticker.c` и дополнительный
`ADD_Server_Manager_FPS.pbo` со счётчиком в слое `3_Game`. Зависимости второго
PBO от ADD и Expansion Core ставят его `DayZGame.OnUpdate()` снаружи ограничителя
Expansion. TL_Core также вызывает `super` на каждом кадре, поэтому порядок
между TL_Core и новым счётчиком не меняет число учитываемых кадров.

Весь новый счётчик и override находятся под `#ifdef SERVER`. На клиенте
подсчёт отсутствует. Отправка HTTP, обход объектов и прочие рабочие шаги ADD
остаются в обновлении миссии; на каждый кадр движка перенесён только счётчик.

`fpsAvg` — число вызовов обновления движка, делённое на фактическое время
`GetTickTime()` между heartbeat. `fpsMin`/`fpsMax` — экстремумы по завершённым
окнам длительностью не менее секунды. Неполное окно входит в среднее, но не
в экстремумы; при отсутствии полного окна экстремумы равны среднему.
Показатель может отличаться от консоли из-за разных интервалов усреднения.

## Проверки и ограничения

Из корня репозитория:

```bash
python3 tools/build_engine_fps.py
python3 tests/test_engine_fps.py
```

Сборка проверяет SHA-256 всех исходных файлов по манифесту релиза и создаёт
`build/engine-fps/ADD_Server_Manager_FPS-v0.9.91.zip`.
Исходный `reference/v0.9.91` не изменяется. Для отката вернуть оригинальную
папку мода в параметрах запуска.

PBO упакованы без сжатия, бинарный config оригинала сохранён, дополнительный
config.cpp остаётся текстовым. Это упаковка, а не компиляция Enforce Script.
DayZ Server и проверка внутри игры в этой среде недоступны.
Архив не подписан: для установки с проверкой подписей нужны собственная
подпись и ключ по принятой на сервере схеме. Оригинальные `.bisign` к
изменённому PBO не подходят. Автообновление менеджера может вернуть оригинал.

Другие замечания к исходной версии описаны в `REVIEW.md` в архиве и
`docs/GAME_MOD_REVIEW.md` репозитория. Они не включены в исправление FPS.
